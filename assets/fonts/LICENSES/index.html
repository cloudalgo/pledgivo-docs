    Font licences#

    Every face served from this directory is a subset built from an SIL Open Font License 1.1 release. The OFL permits redistribution of modified copies (a subset is a modification) provided the licence travels with them and no Reserved Font Name is reused — hence this file, and hence the faces are referenced by their original family names in CSS only as @font-face sources, never rebranded.

    File Family Cut Upstream Licence
    bricolage800.woff2 Bricolage Grotesque 800, subset to the glyphs of the wordmark https://github.com/ateliertriay/bricolage SIL OFL 1.1
    fraunces.woff2 Fraunces variable, latin https://github.com/undercasetype/Fraunces SIL OFL 1.1
    plexsans.woff2 IBM Plex Sans 400–700 variable, latin https://github.com/IBM/plex SIL OFL 1.1
    plexmono400.woff2 IBM Plex Mono 400, latin https://github.com/IBM/plex SIL OFL 1.1
    plexmono500.woff2 IBM Plex Mono 500, latin https://github.com/IBM/plex SIL OFL 1.1

    Full licence text: https://openfontlicense.org/open-font-license-official-text/

    The OFL's one hard prohibition is selling the fonts by themselves. Bundling them inside this documentation site — which is what these subsets are for — is expressly permitted.

    bricolage800.woff2 is subset to the eight glyphs of the product wordmark (2 KB against 39 KB for the full latin cut). That is deliberate: it makes the face unusable as a general display face, so it cannot quietly spread beyond the masthead lockup it was added for.
