    Getting Started

    Quick start#

    The fastest path from a fresh install to a working donation page you can test with a Stripe test card. About 20 minutes.

    This is the express version. For the full explanation of each step, see Installation, Connecting Stripe, and Setup assistant.

    1. Install and assign permissions#

    Install Pledgivo, then assign yourself the Fundraising_Admin permission set. See Installation if any of this is unfamiliar.

    Have an Experience Cloud site ready

    This walkthrough publishes a donation page, which needs a Digital Experience site to publish to. If you don't have one yet, do the one-time setup in Set up your Experience Cloud site first — it takes about 10 minutes.

    2. Connect Stripe in test mode#

    1. Open the Pledgivo app → Settings → Payments.
    2. Create a Payment Account record and connect it to a Stripe account using test mode API keys — a direct secret-key connection stored in a Named Credential, never in a field.
    3. Confirm the connection test passes.

    **What it shows.** The Payment Accounts panel with a "Stripe (Test)" row showing an ACTIVE badge plus its enabled capabilities (Recurring, ACH) after a successful connection test.

    3. Confirm your org basics#

    Open Settings → System → Record Types and confirm Pledgivo detected your account model (standard Contact/Account or Person Accounts) and mapped record types correctly. This is read-only detection — there's nothing to configure unless something looks wrong.

    4. Create a Campaign#

    Create a standard Salesforce Campaign (Type: doesn't matter for Pledgivo). Give it a name and save it.

    5. Add a page design and publish#

    1. On the Campaign, open Settings → Experience Cloud → Page Designs and attach a design — pick a packaged theme to start, no need to customize yet.
    2. Publish the Campaign's donation page. See Set up your first campaign for the full walkthrough, including the Page Canvas composer.

    6. Make a test donation#

    Open the published donation page and submit a donation using one of Stripe's test card numbers (4242 4242 4242 4242, any future expiry, any CVC). You should land on a Thank You step, and — within moments — see a new Opportunity in Closed Won on the Campaign, with a receipt email sent to the test donor's address.

    Why it takes a moment

    Pledgivo doesn't use an inbound webhook to learn a payment succeeded — it asks Stripe directly, both immediately (a guest-side poll right after payment) and on a short backup schedule. See Donations & payments for why.
