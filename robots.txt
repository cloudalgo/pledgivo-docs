# The three Disallow paths below are the deliberately unlisted sections — the
# data model, code and integration references. They still build and still
# answer on their own URLs so we can hand a link to anyone who asks, but they
# are not part of the public site: no nav entry, no inbound link, no search

# Note for whoever edits this next: the Disallow lines are NOT what removes
# these pages from search results. `noindex: true` in each page's front matter
# is — it renders <meta name="robots" content="noindex"> and that is the only
# instruction that de-indexes. The two mechanisms are in mild tension, because
# a crawler that obeys Disallow never fetches the page and so never reads the
# noindex. Both are here by explicit choice: noindex + sitemap removal do the
# de-indexing, and Disallow stops well-behaved crawlers fetching at all. If a
# URL ever needs to be actively removed from an index, drop its Disallow first
# so the noindex can be seen.
