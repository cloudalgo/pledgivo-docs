    Guides

    Post campaign updates and documents#

    Updates and documents are the same record with a different Type. Both live on the campaign, both appear in the tabbed well on its public page, and both stay invisible until you say otherwise.

    Before you start#

    Posts are created from the Campaign Posts related list on a fundraising campaign. If you do not see it, the campaign is on the stock Salesforce layout rather than the one this package ships.

    Assign the Fundraising Campaign layout

    Go to Setup → Object Manager → Campaign → Page Layouts → Page Layout Assignment, and set the Fundraising Campaign Layout for the record type your fundraising campaigns use. This is a one-time step per org — the same one the donor layouts need, and for the same reason: a package cannot assign layouts to your profiles on your behalf.

    Write an update#

    1. Open the campaign, go to Related, and click New on Campaign Posts.
    2. Leave Type on Update.
    3. Give it a Title. It is the headline a donor reads in the timeline, so make it specific — "Trail restoration begins on the eastern ridge", not "Update 3".
    4. Write the Body. Plain text, as long as you like.
    5. Set the Posted Date to the date the thing happened, not the date you wrote it up. Donors see this date and a timeline that jumps around reads as if it were backfilled.
    6. Tick Is Published and save.

    Post Name fills itself in (POST-00001 and up) — it is a filing reference, not something a donor ever sees.

    Nothing appears on the public page until Is Published is ticked. That is the drafting mechanism: write it, leave it unticked, come back to it.

    Publish a document#

    A document post is the same record with two extra moves: set the Type, then attach the file.

    1. New on Campaign Posts, set Type to Document.
    2. Title it the way a donor would ask for it — "2025 audited accounts", "Where your $50 goes". The title is the only label on the download card.
    3. Leave Body blank. It is not rendered on a document.
    4. Save.
    5. On the post's own record page, use the Files related list to upload the file.
    6. Tick Is Published.

    The file has to be attached to the post, not to the campaign. A file on the campaign has no post to render it.

    How a file becomes a public link#

    Attaching the file is the whole of it. Behind the scenes, the package mints a public download link for the file and stores it on the post, together with the file's type and size — that is what fills in the read-only File URL, File Type and File Size fields you can see on the record.

    It has to work this way round because a website visitor has no permission to read a Salesforce file at all. The link is resolved once, by you, and the public page just plays back what was stored.

    If File URL is ever blank on a published document

    Save the post again. The stamp reruns on every save, so a re-save repairs a post whose file was attached in an unusual order or replaced later. Do not type a URL in by hand — the next save overwrites it.

    The download link is permanent and public: anyone with the URL can open the file, whether or not the post is published and whether or not they came from your page. Treat "attach it here" as "publish it to the internet", and keep anything you would not hand to a stranger out of a document post.

    Where they show up#

    Both types land in the tabbed well under the story on the campaign's public page — documents in Documents, updates in Updates. The tabs only render when there is something published behind them, and each tab carries its own count. See Sections and the contact band for the full rule, including the per-campaign toggles that can switch either tab off.

    Controlling the order#

    Within a tab, posts are ordered by Sort Order first and then by Posted Date, newest first.

    Leave Sort Order blank and you get pure date ordering, which is what you want almost always — a blank sorts after every numbered post, so an unordered timeline is never pushed below a single pinned item.

    Fill it in only to pin something to the top: give that one post a low number (1) and leave the rest blank. The annual report that should sit above the newsletters, the venue map that should be the first thing a ticket-holder sees.

    Unpublishing#

    Untick Is Published and save. The post drops out of the tab immediately, and if it was the last one there, the tab goes with it. Nothing is deleted, so you can put it back the same way.
