    Data Model Reference

    Fundraising Page#

    An individual peer-to-peer fundraising page created by a supporter under a Campaign to collect donations on the fundraising app's behalf. There is no standard-object equivalent for a personal, supporter-branded giving page, so it is modeled as a custom object. Belongs to a parent Campaign and, optionally, a Fundraising_Team__c, and rolls up its own donation totals from the Opportunities raised through it.

    custom · 11 fields · ReadWrite · Peer-to-Peer

    Why it exists#

    Peer-to-peer fundraising used to live in a separate extension package; it was merged into base on 2026-07-13 because a fundraiser page can't be cleanly isolated from base Campaign and Opportunity. Fundraising_Page__c is what a supporter gets when they sign up to fundraise on a campaign's behalf — every gift raised through it is still a normal Opportunity, linked back here via Opportunity.Fundraising_Page__c, so the page's total is a rollup of real donations, not a separately-tracked number. A page can optionally belong to a Fundraising_Team__c for team-based fundraising (workplace giving, event teams); when it does, gifts also carry Opportunity.Fundraising_Team__c so team totals aggregate correctly without double-counting.

    Relationships#

    Direction Field Related object Relationship type

    Fields#

    Field Label Type Notes
    Amount_Raised__c Amount Raised Currency Total raised through this fundraiser's page so far. Calculated automatically — do not edit directly.
    Avatar_URL__c Avatar URL Url Web address of the photo shown on this fundraiser's public page. Leave blank to use the default avatar.
    Docs: Read-only from the fundraiser's own signup/edit flow today — there is no in-app photo upload UI that writes this field, so it is populated only via direct record edit or a future upload feature.
    Campaign__c Campaign Lookup → Campaign The campaign this fundraiser is raising money for.
    Contact__c Contact Lookup → Contact The fundraiser (Contact) who created this page. Used in standard Salesforce orgs.
    Donor_Account__c Donor Account Lookup → Account The fundraiser (Person Account) who created this page. Used in Person Account orgs.
    Donor_Count__c Donor Count Number Number of people who have donated through this page. Calculated automatically.
    Goal__c Goal Currency How much this fundraiser is aiming to raise. Shown as their progress goal on the public page.
    Personal_Message__c Personal Message LongTextArea Tell your story — why this cause matters to you. Shown to visitors on your public fundraising page.
    Public_URL_Slug__c Public URL Slug Text The web address ending for this page (e.g. "jane-smith"). Must be unique — no spaces.
    Docs: Resolved by FundraisingPagesSelector against the guest-facing publicFundraiserPage LWC route; uniqueness is case-insensitive so "Jane-Smith" and "jane-smith" cannot collide as two different pages.
    Status__c Status Picklist Whether this page is live and accepting donations (Active), hidden (Inactive), or wrapped up (Closed).
    Team__c Team Lookup → Fundraising_Team__c The team this fundraiser is part of, if any. Leave blank for an individual (non-team) fundraiser.
    Docs: P2PAttributionService.rollupTeams sums Amount_Raised__c across every page with this Team__c set to produce the team's own Amount_Raised__c/Member_Count__c — a page's team total is a live aggregate, not something copied once at page-creation time.
